Четыре шага до чистого обзора

01

Сформулируйте тему

Ключевые слова, must-ключи, boost-ключи. Одна тема — отдельное направление исследования. Сколько тем — столько параллельных потоков литературы.

must: deep learning must: MRI boost: segmentation нейросети · диагностика · 2019–2026
02

Получите чистую выдачу

4 базы параллельно, дедупликация по DOI и заголовку, черновой скор 0–10 по вашим must/boost-ключам — явные промахи уходят вниз списка. Финальное слово за вами: скор — это порядок разбора, а не приговор. Попробуйте сами — виджет живой:

    Как это выглядит на деле

    Никаких стоковых картинок — реальный интерфейс papeer, как есть.

    Разберитесь в теме, а не просто соберите список

    Раздел «Анализ» превращает отобранные статьи в картину поля: темы, ключевые работы, пробелы, граф цитирований. Аналитика считается локально, на вашем компьютере; LLM-черновик обзора — опционально, на вашем ключе.

    Темы выборки.

    TF-IDF и кластеризация прямо на вашем компьютере: сотни статей складываются в понятные темы. Без сети, без отправки данных куда-либо.

    Что читать первым.

    Три рейтинга: самые цитируемые, набирающие обороты и «мосты» между темами — betweenness centrality по графу цитирований.

    Чего не хватает.

    Coverage Gaps: работы, которые цитирует ваша выборка, но которых у вас ещё нет. Добавить в выборку — в один клик.

    Граф цитирований.

    Кто на кого ссылается внутри вашей выборки — по данным Semantic Scholar Graph API.

    Радар: поле следит за собой само.

    Настройте один раз — papeer периодически перепроверяет базы и помечает новые статьи по вашим темам тегом «monitoring». Google Alerts для научной литературы, только без почты и рекламы.

    Похожие на одобренные.

    Рекомендации на основе ваших решений: чем больше разбираете, тем точнее подсказки, что посмотреть следующим.

    Черновик обзора по вашим статьям. На вашем LLM-ключе.

    Подключите любой OpenAI-совместимый ключ (DeepSeek, OpenAI, локальная модель) — papeer сделает саммари каждой скачанной статьи и соберёт из них черновик обзора в Markdown. Это черновик, а не готовая глава: источники показаны рядом с каждым абзацем. Опционально: без ключа работает всё остальное, а сам ключ хранится в системном хранилище ключей вашей ОС.

    Всё для обзора — в одном окне

    Четыре базы. Один запрос. Ноль вкладок.

    Semantic Scholar, OpenAlex, Crossref и arXiv ищутся параллельно. Дубли сливаются по DOI и заголовку — вы видите чистую выдачу, а не четыре каши.

    Сотни статей в час. Без мыши.

    Эвристика по must/boost-ключам расставляет черновой скор 0–10 и задаёт порядок разбора — остаётся листать j/k и жать a/r. Финальное решение всегда за вами.

    «Полный текст недоступен»? Это не наша проблема.

    5 источников открытых полных текстов: arXiv → Semantic Scholar → OpenAlex → Unpaywall → Crossref, плюс headless Chrome против антибот-защит издателей (MDPI, Springer, ScienceDirect).

    BibTeX по одному клику.

    Готовый .bib для LaTeX и CSV для отчётов. Вставили в диссертацию — и пошли дальше по тексту.

    Фильтры, которые складываются. Как Lego.

    Тема, статус, скор, годы, количество цитат — комбинируйте как угодно. Статистика-дашборды показывают картину по каждой теме.

    Ваша база. Ваш компьютер. Точка.

    SQLite локально, сеть — только к API баз и скачивание PDF. Ничего не отправляется, кроме явно вызванных вами запросов к API. Ни аккаунтов, ни «облака».

    Частые вопросы

    papeer работает только с открытыми источниками: arXiv, OpenAlex, Unpaywall, препринты и open-access PDF. Он делает то же, что вы сделали бы вручную через браузер или curl, — просто быстрее и по всем базам сразу. Ответственность за то, как вы используете полученные материалы, остаётся на пользователе.

    Нет. База статей — локальный файл SQLite на вашем диске. Сетевые запросы идут только к API академических баз и при скачивании PDF. Телеметрии, аналитики и «домашних» серверов нет в принципе — можете проверить исходный код, он открыт. Единственное исключение — опциональные LLM-функции (саммари, черновик обзора): запросы уходят на тот LLM-эндпоинт, который вы указали сами, и только по вашему явному действию.

    Опционально. Некоторые издатели (MDPI, Springer, ScienceDirect) прячут PDF за антибот-защитой. Если в системе установлен Chrome, papeer запускает его в headless-режиме и аккуратно забирает открытый PDF. Без Chrome всё остальное работает — просто этот один источник пропускается.

    macOS (Intel и Apple Silicon, один universal-билд), Windows x64 и Linux amd64. Внутри — Go + Wails: нативное окно, маленький бинарник, запуск мгновенный, оперативной памяти ест меньше, чем одна вкладка браузера из тех самых сорока семи.

    Ничем — потому что это не конкуренты, а разные этапы пайплайна. Zotero отлично хранит и цитирует уже отобранное. papeer заходит раньше: находит, скорит, отсекает мусор и отдаёт чистый BibTeX дальше. Связка papeer → BibTeX → Zotero закрывает обзор целиком.

    Ничего страшного: остальные три базы продолжат работать — это называется мягкая деградация. Поиск не падает целиком из-за одного недоступного источника, а упавший поток честно помечается в журнале.

    Без ключа работает почти всё: поиск по 4 базам, скоринг, хоткеи, скачивание PDF, BibTeX/CSV, темы, граф цитирований, рекомендации и Радар. Ключ нужен только для двух LLM-функций — саммари статей и черновика обзора. Подойдёт любой OpenAI-совместимый эндпоинт: DeepSeek, OpenAI или локальная модель.

    Регистрации и аккаунтов нет. Но при создании исследования papeer просит указать валидный e-mail — это не логин, а контактный адрес, который академические API (OpenAlex, Crossref и другие) просят передавать в запросах — так называемый «вежливый пул»: с ним данные отдаются быстрее и стабильнее. E-mail хранится локально и уходит только этим API в составе User-Agent — писем на него не приходит.

    Ключ хранится в системном хранилище ключей вашей ОС — Keychain (macOS), Credential Manager (Windows) или Secret Service/libsecret (Linux), — а не в файле базы и не в открытом виде. Ключ никуда не отправляется, кроме самого LLM-эндпоинта при явном вызове. Если подозреваете компрометацию — отзовите ключ у провайдера и сгенерируйте новый.

    Они строят граф похожих работ в облаке — за подписку и с аккаунтом. papeer бесплатен, работает локально без регистрации и закрывает весь цикл обзора: поиск → разбор → PDF → анализ поля (темы, ключевые работы, пробелы) → черновик обзора → мониторинг новых статей.
