Четыре шага до чистого обзора

01

Сформулируйте тему

Ключевые слова, must-ключи, boost-ключи. Одна тема = одна «ось» исследования. Сколько осей — столько параллельных потоков литературы.

must: deep learning must: MRI boost: segmentation нейросети · диагностика · 2019–2026
02

Получите чистую выдачу

4 базы параллельно, дедупликация по DOI, скор релевантности 0–10. Мусор отсеивается сам. Попробуйте сами — виджет живой:

    Частые вопросы

    papeer работает только с открытыми источниками: arXiv, OpenAlex, Unpaywall, препринты и open-access PDF. Он делает то же, что вы сделали бы вручную через браузер или curl, — просто быстрее и по всем базам сразу. Ответственность за то, как вы используете полученные материалы, остаётся на пользователе.

    Нет. База статей — локальный файл SQLite на вашем диске. Сетевые запросы идут только к API академических баз и при скачивании PDF. Телеметрии, аналитики и «домашних» серверов нет в принципе — можете проверить исходный код, он открыт.

    Опционально. Некоторые издатели (MDPI, Springer) прячут PDF за защитой Akamai. Если в системе установлен Chrome, papeer запускает его в headless-режиме и аккуратно забирает открытый PDF. Без Chrome всё остальное работает — просто этот один источник пропускается.

    macOS (Intel и Apple Silicon, один universal-билд), Windows x64 и Linux amd64. Внутри — Go + Wails: нативное окно, маленький бинарник, запуск мгновенный, оперативной памяти ест меньше, чем одна вкладка браузера из тех самых сорока семи.

    Ничем — потому что это не конкуренты, а разные этапы пайплайна. Zotero отлично хранит и цитирует уже отобранное. papeer заходит раньше: находит, скорит, отсекает мусор и отдаёт чистый BibTeX дальше. Связка papeer → BibTeX → Zotero закрывает обзор целиком.

    Ничего страшного: остальные три базы продолжат работать — это называется мягкая деградация. Поиск не падает целиком из-за одного недоступного источника, а упавший поток честно помечается в журнале.
